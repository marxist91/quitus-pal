## Pour les Utilisateurs

### Se Connecter

1. **Avec votre Email**
   - Allez sur la page de connexion
   - Email : `jdupont@togoport.tg`
   - Mot de passe : `TogoPort2024@`
   - Cliquez sur "Se Connecter"

2. **Avec votre Username**
   - Allez sur la page de connexion
   - Username : `jdupont`
   - Mot de passe : `TogoPort2024@`
   - Cliquez sur "Se Connecter"

### Changer le Mot de Passe (RECOMMANDÉ à la première connexion)

1. **Accédez à la Page de Changement**
   - Cliquez sur votre nom en haut à droite (`Jean Dupont`)
   - Dans le menu dropdown, sélectionnez "Changer le mot de passe"

2. **Remplissez le Formulaire**
   - **Mot de passe actuel** : `TogoPort2024@`
   - **Nouveau mot de passe** : Votre nouveau mot de passe (minimum 8 caractères)
   - **Confirmer le nouveau mot de passe** : Retapez le même mot de passe
   - Cliquez sur "Changer le mot de passe"

3. **Confirmation**
   - Vous verrez un message de succès
   - Vous restez connecté automatiquement
   - Utilisez votre nouveau mot de passe lors de la prochaine connexion

## Points Importants

### ✅ Ce qui fonctionne maintenant :

- **Connexion par email** : Utilisez votre email au lieu du username
- **Mot de passe par défaut** : `TogoPort2024@` assigné automatiquement
- **Changement de mot de passe** : Interface simple et sécurisée
- **Nom complet affiché** : Votre prénom et nom apparaissent dans la navbar

### 🔒 Sécurité :

- Le mot de passe par défaut est **temporaire**
- **Changez-le immédiatement** lors de votre première connexion
- Minimum **8 caractères** pour les nouveaux mots de passe
- La session reste active après changement de mot de passe

### 📝 Bonnes Pratiques :

1. **Admins** : Encouragez les utilisateurs à changer le mot de passe par défaut
2. **Utilisateurs** : Créez un mot de passe fort (lettres, chiffres, symboles)
3. **Tous** : Déconnectez-vous toujours après utilisation
